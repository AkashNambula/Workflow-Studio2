# Recent Runs

## Feature purpose
Review the latest workflow executions that were recently recorded in the system.

## Navigation path
- Open the admin dashboard and select Recent Runs from the navigation panel.

## Step-by-step usage
1. Sign in as an Admin user.
2. Open the admin dashboard.
3. Select Recent Runs.
4. Search or filter the runs to focus on specific workflow activity.

## Required inputs
- Optional search term
- Optional status filter

## Expected output
- A list of recent workflow executions appears with current status and workflow context.

## Common user questions
- Why do I not see recent runs? No runs have been recorded yet.
- Can I filter the list? Yes, you can search by workflow name and filter by status.
