# Saved Workflows

## Feature purpose
Browse and reopen workflows that were previously saved in the system.

## Navigation path
- From the main workflow builder, open the Saved Workflows section in the sidebar.
- Admin users can also access this view from the admin dashboard.
- The route /saved-workflows is also supported by the frontend router.

## Step-by-step usage
1. Sign in with an account that has operational access.
2. Open the workflow builder.
3. Expand the Saved Workflows section in the sidebar.
4. Review the available workflow cards.
5. Click a workflow card to load it into the canvas.
6. Edit or run the workflow as needed.

## Required inputs
- No additional form input is required.
- You must have at least one saved workflow already present in the system.

## Expected output
- The selected workflow definition is loaded into the canvas.
- The canvas displays the saved nodes and connections.

## Common user questions
- Why don’t I see any workflows? No workflows have been created or saved yet.
- Can I open a workflow from the admin dashboard? Yes, the admin dashboard includes a Saved Workflows view.
- What if I want to create a new workflow instead? Use the main workflow builder canvas and design a new workflow from scratch.
